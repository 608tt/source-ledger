# Contributing

Start with a minimal reproducer or a concrete user task in an issue. Small fixes,
clear examples, translations and improvements to error handling are welcome.

Clone the repository and work on a branch. Run the tests described in the README,
keep generated databases out of commits, and include a focused regression test
when changing behavior. Open a pull request explaining what changed and how you
verified it. Do not include private source material or account credentials.

This project is an early release. Keep additions aligned with its stated scope;
large integrations should begin with a design discussion.
