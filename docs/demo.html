Reading is a separate step

A useful knowledge library should distinguish imported records from reviewed excerpts. Updating a source invalidates its old review marks. Keyword matches are retrieval evidence; they do not prove that a generated answer is correct.

A review loop for small teams

A small annotation project should separate labeling from review. Import a dataset, label each item, then approve or return it with a reason. Keep a stable source identifier so a later export can explain where each decision came from. This synthetic note is included to demonstrate traceable search.
